## Why RizzUI?

RizzUI is a React component library built for **React 19** and **Tailwind CSS v4**: accessible, type-safe, and easy to theme with CSS variables. Pick the workflow that fits your project below.

- **Modern design** — Minimal components that look great out of the box
- **Lightweight** — Tree-shakeable exports; import only what you need
- **Type-safe** — Full TypeScript support with strong autocomplete
- **Accessible** — Built with WCAG-oriented patterns in mind
- **Customizable** — Theming via CSS variables, Tailwind v4–first setup
- **Dark mode** — Works with common theme providers and data attributes

<br />

## Getting started

Use RizzUI in one of two ways. Each path has its own README with install steps, configuration, and examples.

### Install from npm

Add the published **`rizzui`** package and import components from `node_modules` (for example `rizzui/button`). Best when you want upgrades via semver and a smaller surface area in your repo.

**[Full guide: packages/ui/README.md](packages/ui/README.md)** — peer dependencies, Tailwind v4 globals and `@source`, PostCSS, imports, and theme snippets.

### Use rizzui-cli

Run **`rizzui-cli`** in an existing **Next.js** or **TanStack Start** app to scaffold Tailwind-friendly files and copy component **source** into your project with `rizzui init` and `rizzui add`. Best when you want to own and customize UI code in your repository.

**[Full guide: packages/cli/README.md](packages/cli/README.md)** — commands, layout under `components/ui`, bundled sources, and troubleshooting.
